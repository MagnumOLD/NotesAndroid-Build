# Прототип NotesAndroid: проверка учёта времени

Эта ветка собирается как отдельное приложение с package ID `com.magnumold.notes.prototype`. Его можно установить рядом со стабильной версией NotesAndroid.

## Первый запуск

1. Создай обычную задачу и добавь подзадачу.
2. Открой подзадачу.
3. Нажми меню в правой части верхней панели, чтобы раскрыть подробности.
4. В блоке «Время» проверь лимит и запусти таймер.
5. При первом запуске разреши уведомления.
6. Разреши точные сигналы в системных настройках специального доступа. Без этого Android может задержать сигнал.

## Проверка фоновой работы

- Запусти таймер на 1–2 минуты.
- Сверни приложение и пользуйся другими приложениями.
- Повтори с выключенным экраном.
- Проверь уведомление и звук по окончании.
- Останови таймер из уведомления или вернись в подзадачу.
- Закрой и снова открой приложение: завершённая рабочая сессия должна остаться в учёте.

## Режимы окончания

- «Только сигнал» — уведомляет об окончании лимита, но продолжает считать фактическое время до ручной остановки.
- «Остановить» — автоматически завершает рабочую сессию.
- «Перерыв» — сохраняет рабочую сессию и запускает отдельный таймер перерыва. Перерыв в фактическое рабочее время не включается.

Настройки лимита, режима окончания, длительности перерыва и звука общие для всех подзадач.

## Ограничения текущего этапа

- Одновременно работает один таймер на всё приложение.
- Принудительная остановка приложения в системных настройках запрещает Android выполнять его фоновые задачи до следующего ручного запуска.
- Для точного сигнала требуется разрешение Android на точные будильники; без него используется менее точный системный механизм.
- Учёт времени пока хранится отдельно от JSON-резервной копии. Экспорт и импорт истории добавим до выдачи тестовой сборки.
