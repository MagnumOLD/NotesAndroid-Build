# NotesAndroid Build

Публичная сборочная копия проекта NotesAndroid.

Здесь опубликован только снимок исходного кода из ветки `proto` приватного репозитория. История основного проекта и его другие ветки сюда не переносятся.

## Сборка APK

GitHub Actions запускает сборку при каждом push в `main` или вручную через вкладку **Actions**.

Workflow выполняет:
- unit-тесты;
- сборку debug APK;
- Compose instrumentation tests на Android Emulator;
- публикацию `app-debug.apk` как артефакта workflow на 14 дней.

## Получение APK

1. Открой вкладку **Actions**.
2. Выбери последний успешный запуск **Build Android APK**.
3. Внизу страницы скачай артефакт **NotesAndroid-debug-apk**.
4. Распакуй ZIP и установи `app-debug.apk`.

Это отладочная сборка (debug), не релизная версия для Google Play.
